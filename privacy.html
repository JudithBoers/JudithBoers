Privacy op mijn website

Hier lees je meer over cookies en gegevens op deze website. Klik op een onderwerp om de uitleg te openen.

Wat zijn cookies?

Cookies zijn kleine bestanden die een website in je browser kan bewaren. Ze kunnen bijvoorbeeld instellingen onthouden. Sommige cookies worden gebruikt om bezoekers te volgen.

Waarvoor dient het privacykoekje?

Ik gebruik op deze website geen eigen analytics of trackingcookies om bezoekers te volgen.

Het gehaakte koekje opent informatie over privacy. Het is geen knop om cookies te accepteren of te weigeren. Het openen of sluiten verandert niets aan de gegevens die GitHub Pages voor beveiliging verwerkt.

Hoe worden de lettertypes geladen?

De lettertypes op deze website zijn gedownload en worden vanuit de bestanden van mijn eigen website geladen. Je browser hoeft hiervoor geen verbinding te maken met Google Fonts.

Wat is Digitaal Tuintje?

Mijn website is aangesloten bij Digitaal Tuintje. Daarmee laadt mijn website een script van Digitaal Tuintje. Je browser maakt daarvoor verbinding met de server van Digitaal Tuintje..

Mijn docent, die dit onderdeel beheert, heeft in de les aangegeven dat hij geen bezoekersgegevens opslaat of gebruikt.

Welke gegevens verwerkt GitHub Pages?

Deze website wordt gehost via GitHub Pages. Dat betekent dat GitHub de bestanden van mijn website beschikbaar maakt voor bezoekers.

Wanneer je deze website bezoekt, legt GitHub je IP-adres vast voor beveiliging. Dit gebeurt ook als je niet bent ingelogd bij GitHub.

Een IP-adres is een adres waarmee je internetverbinding op het internet wordt herkend.
